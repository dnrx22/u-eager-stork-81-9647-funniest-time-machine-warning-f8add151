One warning label for a time machine, at most 120 characters — the thing
a careless traveller would do first, warned about in the smallest space
possible:

> WARNING: Do not wave at yourself. You know what you did, and so does he. Paradoxes not covered by warranty.

## Run it

```sh
python3 main.py
```

This writes the label (no trailing newline) to `entry.txt` inside
`MAKEFUN_OUTPUT_DIR` (or `/output` when that is unset), then prints the
byte count, character count, and sha256. The program is deterministic:
two runs produce byte-identical output. Python standard library only,
no network access.
